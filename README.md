# Trabajo-practico-integrador
Argentina programa 4.0 tramo 1 desarrolador web 

Codigo generado en colaboracion con Jose Franciso Ruski, Jesica Damiani y Ruben Sapena para el trabajo practico integrador
del tramo 1 de Argentina Programa 4.0 en la instancia de desarrollador web inicial en la que se creo un sitio de ecomerce
destinado a la venta de insumos teconologicos

### Actualizaciones recientes (14–16 de noviembre de 2026)

- Se adaptaron el encabezado y el pie de página para que se reorganicen en pantallas móviles, tabletas y escritorio.
- Se renovó la portada con una ilustración tecnológica, un nuevo mensaje principal y una grilla adaptable para los logos de partners.
- Se mejoraron las tarjetas de productos y se incorporaron botones funcionales para añadir productos al carrito.
- Se actualizaron visualmente las páginas de equipo, servicios y pedido, incluido el formulario de contacto, con diseños adaptables.
- Se ordenaron estilos y recursos locales para mantener una presentación más consistente entre las páginas.
